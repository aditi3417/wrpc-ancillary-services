# Assumptions Log

| ID | Assumption | Reason | Status |
|----|------------|--------|--------|
| A01 | Each Monday–Sunday week is assigned to the calendar year containing its Thursday, i.e. at least 4 of its 7 days (ISO 8601 week-year). The same rule is applied to months (our extension; ISO defines week-years only). CY2025 = 30.12.2024–28.12.2025 (52 weeks); CY2026 to Aug = 29.12.2025–30.08.2026 (35 weeks). | Gives every week exactly one year with no overlap; follows a recognised standard. | Confirmed |
| A02 | Two-digit years in titles (dd.mm.yy) are 20yy. | All listed files are from 2023 onwards; no 19yy dates are plausible. | Confirmed |
| A03 | A title date written as "revised dd.mm.yyyy" (without "on") is treated the same as "Revised on" / "Updated on". | 6 titles on the 2026 tab use this form; the meaning is the same. Used only for the date_mismatch check, never for ordering. | Confirmed |
| A04 | Titles naming specific stations (e.g. "Revised TRAS SRAS & SCUC of TPCL_Mundra", "Revised TRAS of GMR Warora") get scope UNKNOWN and are excluded from the step 02 provisional selection. | They do not clearly match a defined scope and look like partial (station-level) revisions; letting them supersede a full statement would drop other stations. They are still on the download list and flagged for manual inspection. | Superseded by A07 (now scope STATION_SPECIFIC, handled as overlays) |
| A05 | Upload timestamps from filenames (ddmmyyyyHHMMSS) are compared as naive local times. | Only their relative order is used, and all come from the same site. | Confirmed |
| A06 | If any candidate for a week x section has no valid upload_ts, no file is selected for it and it is flagged "unranked". | Ordering would otherwise be a guess. (No in-window cases at present.) | Confirmed |
| A07 | Revisions are modelled as base plus overlays: the newest file covering a whole section is the base; narrower revisions (emergency or station-specific) are applied on top. Older overlays are assumed to be incorporated in a newer base, to be verified against the data. | Narrow revisions (one station, or one table) must not replace a full statement for all stations; a base uploaded after an overlay is expected to already include it. As of the current fetch, no older overlays exist: every overlay was uploaded after its week’s base. | Superseded by A12 |
| A08 | Page types use the given keyword phrases plus refinements found in the data: "Account in Shortfall/Emergency Condition" also identify TRAS_SHORTFALL/EMERGENCY (station-specific pages lack "Format-TRAS-III"); "by the SCUC Generator(s)" also identifies SCUC; "Mailing list" matches with or without the space; "Day Ahead" alone counts as TRAS_MARKET only on non-consolidated pages; WRLDC_EMAIL is not assigned to mailing-list pages. | The original phrases came from one Dec 2025 file; these cases were checked against other files' page text. | Open |
| A09 | A page without its own heading inherits the type of the last table on the previous page only with evidence of continuation: the "WRPC <X> Account … Page N" footer continues, an email printout repeats the same print header, or mailing-list numbering continues. A page with its own statement heading never inherits. | Avoids guessing; one "Format-TRAS-III … No data found" page (trasjun25.2b_rev2 p5) would otherwise have been mislabelled. | Open |
| A10 | Scanned pages (no text, image covering ≥50% of the page) cannot be classified by keywords and stay UNKNOWN; those before the mailing list are only hinted as probable cover letters (scan_position_hint), not classified. | No OCR in this step; position is a hint, not evidence. | Open |
| A11 | The TRAS-III layout depends on when a file was produced, not on the week it covers: files issued up to about July 2025 use one combined Shortfall/Emergency table; later files, including re-issues of earlier weeks, use separate tables. Step 06 must detect the layout per file. | Combined-layout tables have no condition column or sub-headings; Shortfall and Emergency cannot be separated for files issued up to July 2025. | Confirmed |
| A12 | File roles are decided by content. Completeness is judged on the consolidated table where both the candidate and the same week's comparison base have one (it lists every station, including zeros): a file is a complete restatement of a section if its consolidated station count is at least 90% of the base's and every station missing from its section tables shows 0 in that section's column of its own consolidated table (dropped-row check, A15); a non-zero or unreadable missing station makes it needs_review. Without a consolidated table, the per-table rule applies: at least 90% of the base's station count in every table of the section. Otherwise the file is an overlay. Per-table ratios are kept as secondary evidence. Titles are not used to decide roles. | Titles proved unreliable: 10 of 19 "overlay" titles were full restatements (step 04 station counts). A file re-issued for one section becomes the base for every section it completely contains; value differences against the previous base are reported in step 07. | Open |
| A13 | Overlays that print no week on their pages are assigned to weeks from their website title. | 5 station-specific overlays print no week period; their titles give one. | Open |
| A14 | A TRAS-III page with its own heading and "No data found" (condition not stated) counts as the missing one of the two separate TRAS-III tables, present but empty, when exactly one of TRAS_SHORTFALL/TRAS_EMERGENCY is otherwise missing. The slot is flagged explicit_no_data_table. | Only case: base for week 2025-06-09 (trasjun25.2b_rev2 p5). Without this, the week's own base would fail the TRAS completeness check. | Open |
| A15 | Stations absent from a section table but listed with 0 for that section in the same file's consolidated table are treated as having zero charges for that section, not missing data. Example: the 8 IPP stations' Emergency charges in 2025-06-30 (trasjun25.5b). | Some re-issues drop zero-charge rows from section tables; the consolidated table still lists them. | Open |
| A16 | A page with no statement heading and no "WRPC … Page N" footer continues the previous page's last table (inheritance type row_number) only if that table is a statement table type, the page's first numbered line is a table row (station name followed by a numeric column), and its row number equals the previous page's last table row number + 1. | Found one consolidated continuation page without heading or footer (trasjun25.5 p13); continuing row numbering is evidence of continuation, and the three conditions avoid matching numbered text such as the TRAS-I registration form. | Open |
| A17 | Table cells are read with pdfplumber's ruled-line table detection (src/table_reader.py). A cell that wraps over several lines is joined: in the station-name column, without a space if the joined name appears unwrapped elsewhere in the corpus (or with a space if that spaced form does); in text cells (every fragment contains a letter), with a space; anything else with a space and flagged ambiguous_join. No cell is dropped; the raw text with line breaks is kept beside the joined text. | Long station names wrap inside their cell (e.g. "AGE24AL_PSS3_KPS⏎1_S"); a name dictionary from unwrapped occurrences decides the join without guessing, while status text ("Payable to⏎Pool⏎Account") needs spaces. | Open |
| A18 | The two June 2026 TRAS tables with a 'Shortfall Condition' heading but 'Emergency' column labels (trasjun26.2a, trasjun26.3a) are treated as Shortfall: in each week's base file those stations appear only in Shortfall, with consolidated Emergency = 0. | Step 06 evidence: all 6 stations are in the base's Shortfall table and absent from its Emergency table; neither overlay file has a consolidated table to compare against. | Open |
| A19 | TRAS-Down energy is stored as a positive quantity; the as-published sign is kept in value_as_published (older combined-layout files sometimes print it negative). The same rule is applied to SRAS DOWN regulation, which is always printed negative. | Down energy is a quantity; its direction is carried by the direction column. 12 selected TRAS-Down values are printed negative (combined layout, Jan–May 2025); the rupee columns reconcile either way. | Open |
